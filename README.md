# GUI Browser

GUI Browser is a Minecraft 1.12.2 Cleanroom/Forge mod that aims to collect GUI-capable interactions into a single browser-style shell.

## Project Identity

- Mod ID: `guibrowser`
- Mod Name: `GUI Browser`
- Author: `zzhalex233`
- Repository: <https://github.com/zzhalex233/GUI-Browser>

## Development

- Target Minecraft version: `1.12.2`
- Loader stack: Cleanroom + Forge + Mixin-ready Unimined setup
- Run the client from IntelliJ with the Gradle task `2. Run Client`, or from terminal with `.\gradlew.bat runClient`
- Add mod dependencies in `gradle/scripts/dependencies.gradle`

## Current Status

The repository has been cleaned from the starter template and is ready for GUI Browser feature work.
